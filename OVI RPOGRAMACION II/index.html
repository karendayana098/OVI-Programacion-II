Programación II

Programación Orientada a Objetos

Bienvenidos al Objeto Virtual de Información (OVI) de Programación II. En este espacio encontrarás contenidos educativos relacionados con la Programación Orientada a Objetos y su aplicación mediante el lenguaje de programación Java.

El propósito de este OVI es presentar los conceptos de una manera clara, organizada e interactiva, facilitando el aprendizaje y la comprensión de los principales elementos de la programación orientada a objetos.

Objetivo general

Comprender los fundamentos de la Programación Orientada a Objetos mediante el estudio de sus principales conceptos, características y relaciones, con el propósito de aplicarlos en el desarrollo de programas utilizando Java.

Introducción

La Programación II permite profundizar en los conocimientos necesarios para desarrollar programas de manera estructurada y organizada. Uno de los enfoques más utilizados en el desarrollo de software es la Programación Orientada a Objetos (POO).

La POO permite representar elementos de un problema mediante objetos que poseen características y comportamientos. Para ello se utilizan conceptos como clases, objetos, atributos y métodos.

Además, la Programación Orientada a Objetos incorpora principios como la encapsulación, la herencia y el polimorfismo, los cuales permiten crear programas reutilizables, organizados y fáciles de mantener.

A lo largo de este OVI se estudiarán estos conceptos utilizando ejemplos relacionados con Java, con el objetivo de facilitar su comprensión y aplicación.

Conceptos principales

Clases

Son estructuras que permiten definir las características y comportamientos que tendrán los objetos.

Objetos

Son instancias de una clase que poseen atributos y pueden realizar diferentes acciones mediante sus métodos.

Encapsulación

Permite proteger los datos internos de un objeto y controlar la forma en que estos pueden ser utilizados o modificados.

Herencia

Permite que una clase pueda adquirir características y comportamientos de otra clase.

Polimorfismo

Permite que objetos de diferentes clases puedan responder de distintas formas ante una misma operación.

LECTURA 01

Clases y objetos

En la Programación Orientada a Objetos, las clases y los objetos son elementos fundamentales. Una clase funciona como un modelo que define las características y comportamientos que tendrán sus objetos.

¿Qué es una clase?

Una clase es una estructura que permite definir atributos y métodos. Los atributos representan las características de los objetos, mientras que los métodos representan las acciones que pueden realizar.

¿Qué es un objeto?

Un objeto es una instancia de una clase. Esto significa que podemos crear diferentes objetos utilizando una misma clase, pero cada objeto puede tener valores diferentes.

Ejemplo en Java

class Persona {

    String nombre;
    int edad;

    void saludar() {
        System.out.println("Hola");
    }
}

Persona persona1 = new Persona();

persona1.nombre = "Karen";
persona1.edad = 19;

Elementos principales

  • Clase: modelo para crear objetos.
  • Objeto: instancia de una clase.
  • Atributos: características del objeto.
  • Métodos: acciones que puede realizar.
Referencia APA:
Sierra, K., & Bates, B. (2008). Head First Java (2nd ed.). O'Reilly Media.
LECTURA 02

Encapsulación

La encapsulación es uno de los principios fundamentales de la Programación Orientada a Objetos. Consiste en proteger los datos internos de un objeto y controlar la manera en que estos pueden ser utilizados o modificados.

¿Qué es la encapsulación?

La encapsulación permite ocultar los detalles internos de una clase y proporcionar métodos para acceder a los datos de manera controlada. En Java se utilizan modificadores de acceso como private, public y protected.

Ejemplo en Java

class Persona {

    private String nombre;

    public void setNombre(String nombre) {
        this.nombre = nombre;
    }

    public String getNombre() {
        return nombre;
    }
}

¿Por qué es importante?

  • Protege los datos de una clase.
  • Permite controlar el acceso a la información.
  • Facilita el mantenimiento del código.
  • Ayuda a organizar mejor los programas.
Referencia APA:
Deitel, P., & Deitel, H. (2017). Java: How to Program (11th ed.). Pearson.
LECTURA 03

Herencia

La herencia es un mecanismo de la Programación Orientada a Objetos que permite que una clase pueda adquirir características y comportamientos definidos en otra clase.

¿Cómo funciona?

La clase que proporciona sus características se conoce como superclase o clase padre, mientras que la clase que las recibe se conoce como subclase o clase hija. En Java, la herencia se implementa utilizando la palabra reservada extends.

Ejemplo en Java

class Animal {

    void comer() {
        System.out.println("El animal está comiendo");
    }
}

class Perro extends Animal {

    void ladrar() {
        System.out.println("El perro está ladrando");
    }
}

Ventajas de la herencia

  • Permite reutilizar código.
  • Reduce la repetición de instrucciones.
  • Facilita la organización de las clases.
  • Permite establecer relaciones entre clases.
Referencia APA:
Schildt, H. (2018). Java: The Complete Reference (11th ed.). McGraw-Hill Education.
LECTURA 04

Polimorfismo

El polimorfismo es uno de los principios de la Programación Orientada a Objetos. Permite que una misma operación pueda producir diferentes comportamientos dependiendo del objeto que la ejecute.

¿Cómo funciona?

El polimorfismo permite trabajar con diferentes objetos utilizando una referencia común. Cada objeto puede implementar el comportamiento de una manera diferente.

Ejemplo en Java

class Animal {

    void sonido() {
        System.out.println("Sonido del animal");
    }
}

class Perro extends Animal {

    void sonido() {
        System.out.println("El perro ladra");
    }
}

class Gato extends Animal {

    void sonido() {
        System.out.println("El gato maúlla");
    }
}

Importancia

  • Permite utilizar una misma referencia para diferentes objetos.
  • Facilita la reutilización del código.
  • Permite desarrollar programas más flexibles.
  • Facilita la implementación de diferentes comportamientos.
Referencia APA:
Deitel, P., & Deitel, H. (2017). Java: How to Program (11th ed.). Pearson.
